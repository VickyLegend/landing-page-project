# Creative Agency Landing Page

A responsive modern landing page built using HTML5 and CSS3.  
This project demonstrates layout structuring, Flexbox usage, and responsive design principles.

## 🚀 Features
- Clean responsive layout
- Flexbox-based navigation and sections
- Mobile-friendly design using media queries
- Simple UI with modern styling

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox + Media Queries)

## 📱 Responsive Design
Optimized for mobile, tablet, and desktop screens.

## 🎯 Purpose
This project was built to strengthen frontend development fundamentals and practice real-world website layout structuring.
